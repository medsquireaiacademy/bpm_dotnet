## 1. Authentication & Profile (`/api/auth`)

### 1.1 Admin Login
- **URL**: `POST /api/auth/login`
- **Description**: Authenticates an administrator and returns user details with a session token.
- **Request Body**:
  ```json
  {
    "username": "admin",
    "password": "Password123"
  }
  ```
- **Responses**:
  - `200 OK`: `SuccessResponse<AuthResponseDto>`
  - `401 Unauthorized`: Invalid credentials.

### 1.2 Get Current Profile
- **URL**: `GET /api/auth/me`
- **Description**: Fetches current authenticated admin user profile.
- **Responses**:
  - `200 OK`: `SuccessResponse<AdminUserDto>`
  - `404 Not Found`: Profile not found.

### 1.3 Update Admin Profile
- **URL**: `PUT /api/auth/profile`
- **Description**: Updates the current admin user's name, email, phone, or avatar.
- **Request Body**:
  ```json
  {
    "fullName": "System Administrator",
    "email": "admin@beeproperties.com",
    "phone": "+91 9876543210",
    "avatarUrl": "/uploads/avatar.png"
  }
  ```
- **Responses**:
  - `200 OK`: `SuccessResponse<AdminUserDto>`

### 1.4 Change Admin Password
- **URL**: `POST /api/auth/change-password`
- **Description**: Changes the admin password after verifying the current password.
- **Request Body**:
  ```json
  {
    "currentPassword": "OldPassword123",
    "newPassword": "NewStrongPassword456"
  }
  ```
- **Responses**:
  - `200 OK`: `SuccessResponse`
  - `400 Bad Request`: Current password incorrect.

### 1.5 Get Recent Activities
- **URL**: `GET /api/auth/activities`
- **Query Parameters**:
  - `limit` (int, default: 10): Max items to return.
  - `type` (string, optional): Activity type filter.
- **Responses**:
  - `200 OK`: `SuccessResponse<List<ActivityDto>>`

### 1.6 Record Activity
- **URL**: `POST /api/auth/activities`
- **Description**: Manually logs an audit/activity event.
- **Request Body**:
  ```json
  {
    "type": "PropertyCreated",
    "description": "Added new property Bee Heights",
    "entityId": "PROP-001",
    "entityType": "Property"
  }
  ```
- **Responses**:
  - `201 Created`: `SuccessResponse<ActivityDto>`

## 2. Dashboard (`/api/dashboard`)

### 2.1 Get Summary Metrics
- **URL**: `GET /api/dashboard/metrics`
- **Description**: Retrieves high-level KPI metrics (total properties, flats, occupancy rate, active agencies, open tickets, security staff on duty).
- **Responses**:
  - `200 OK`: `SuccessResponse<DashboardMetricsDto>`

### 2.2 Get Service Request Charts
- **URL**: `GET /api/dashboard/charts`
- **Query Parameters**:
  - `propertyId` (string, optional): Filter by property.
  - `period` (string, optional): E.g., `weekly`, `monthly`, `yearly`.
- **Responses**:
  - `200 OK`: `SuccessResponse<ServiceRequestChartsDto>` (chart datasets, category distribution, resolution times).

### 2.3 Get Pending Approvals
- **URL**: `GET /api/dashboard/pending-approvals`
- **Description**: Retrieves summary lists of agencies, property assignments, and tickets awaiting approval.
- **Responses**:
  - `200 OK`: `SuccessResponse<PendingApprovalsSummaryDto>`

## 3. Property Management (`/api/property`)

### 3.1 Get All Properties
- **URL**: `GET /api/property`
- **Query Parameters**:
  - `searchTerm` (string, optional): Property name, code, address.
  - `status` (string, optional): `Active`, `Under Construction`, `Maintenance`.
  - `city` (string, optional)

- **Responses**:
  - `200 OK`: `SuccessResponse<List<PropertyResponse>>`

### 3.2 Get Property Metrics Summary
- **URL**: `GET /api/property/summary`
- **Query Parameters**:

## 10. Utility / Weather (`/weatherforecast`)

### 10.1 Get Sample Weather Forecast
- **URL**: `GET /weatherforecast`
- **Description**: Default ASP.NET Core sample diagnostic endpoint.
- **Responses**:
  - `200 OK`: Array of forecast records (`date`, `temperatureC`, `temperatureF`, `summary`).
